## 3) Core Logic (must implement)

### 3.1 Flatten navigation

Create helper:

* `flattenNav(navItems)` => returns flat array of nodes with parent chain
* Each node:

  * `label`
  * `path`
  * `roles/permissions/guard`
  * `tabs`
  * `actions`
  * `meta` (branchScoped/adminOnly etc.)

### 3.2 Access check

Implement `canUserAccess(node, user)` using nav.ts rules:

Priority order:

1. If node has `canAccess(user)` function -> use it
2. else if node has `roles` -> `roles.includes(user.role)`
3. else if node has `permissions` -> check from user permissions
4. else default allow (but log warning in console)

### 3.3 Derive allowed pages

`allowedNodes = flatNodes.filter(n => n.path && canUserAccess(n,user))`

### 3.4 Tabs count

If tabs exist:
`totalTabs = sum(node.tabs.length)`
Else: 0

### 3.5 Actions count

If actions exist:
`totalActions = sum(node.actions.length)`
Else: 0
